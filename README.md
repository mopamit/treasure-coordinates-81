# היכן התיבה? — גרסה פשוטה ומדויקת

יישומון לימודי בעברית שממחיש למה צריך מערכת צירים.

- משתמש במפה הפשוטה החדשה בלבד.
- 10 מיקומי אוצר קבועים שהוגדרו לפי התיאורים המאושרים.
- בכל משחק נבחרים 3 מיקומים שונים.
- תיבת האוצר מופיעה 5 שניות ואז נעלמת.
- התלמיד מתאר במילים.
- המערכת מפרשת יחס מרחבי ובוחרת רק מתוך 10 המקומות המאושרים — אין מיקומים מומצאים.
- אם התיאור חלש או דו-משמעי, המערכת מבקשת פירוט נוסף.
- רק בסוף שלושת הסיבובים מופיעה מערכת צירים.

לפרסום ב-GitHub Pages: העלו את כל הקבצים כפי שהם והפעילו Pages מה-branch הראשי.
