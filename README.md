# היכן מוסתרת תיבת האוצר? — גרסה 2

חלצו את התיקייה ופתחו את index.html בדפדפן. להפעלה ב-GitHub Pages העלו את כל תוכן התיקייה לשורש האתר, כולל assets. אין צורך בהתקנת תלויות, שרת או מפתח API.

המשחק כולל 15 מקומות מאתגרים ושלושה סיבובים בכל משחק, חמש שניות צפייה, תיאור חופשי, רמז אחרי ניסיון ראשון, משוב נכון/שגוי, צלילים עם השתקה ומערכת צירים השומרת על אותם מקומות מקוריים בדיוק.

המאגר נבחר ללא החזרה באמצעות localStorage באותו דפדפן; לאחר מיצויו מתחילה הגרלה חדשה. אם אחסון מקומי חסום, הסדר נשמר כל עוד הדף פתוח. לחיצה על משחק חדש או איפוס נוטשת את המשחק הנוכחי. התשובות אינן נשלחות או נשמרות מחוץ לדף; רק רשימת המקומות שעוד לא הוגרלו נשמרת בדפדפן.

REVIEW.md כולל ביקורת מפורטת מול כל ההערות, פירוט בדיקת ההצלחה ומגבלות פענוח השפה. ASSETS.md מפרט את מקור נכסי פריזמה.

הקבצים app.js, index.html, styles.css וכל תיקיית assets דרושים להפעלה. מסמכי Markdown מיועדים למורה ולתחזוקה. המפה והגופנים המקוריים נשמרו.
